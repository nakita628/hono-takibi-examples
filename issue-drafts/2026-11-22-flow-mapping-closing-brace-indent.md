# YAML flow mapping whose closing `}` is at the parent key's indentation is rejected (`deficient indentation`)

## Summary

`hono-takibi` stops with `deficient indentation` on a multi-line flow mapping whose closing `}` is at the
same indentation as the key that owns it. PyYAML parses the same document without complaint.

## Reproduction

`openapi.yaml`:

```yaml
openapi: 3.1.0
info:
  title: flow-mapping-indent-repro
  version: 1.0.0
paths:
  /x:
    get:
      responses:
        200:
          description: ok
          content:
            application/json:
              schema:
                type: object
              example: {
                "a": "b"
              }
        400:
          description: bad request
```

```bash
npx hono-takibi@0.32.5 openapi.yaml -o routes.ts
```

## Actual

```
ERROR
  Error parsing openapi.yaml: deficient indentation (17:15)

 14 |                 type: object
 15 |               example: {
 16 |                 "a": "b"
 17 |               }
```

```bash
python3 -c "import yaml; yaml.safe_load(open('openapi.yaml')); print('PyYAML: parses fine')"
# PyYAML: parses fine   (PyYAML 6.0.1)
```

## Expected

Either the document is read (as PyYAML does), or the message says what to change. The closing `}` is
the same width as `example:`, and indenting it one more space makes the document pass.
