# angular-query hooks import the deprecated `@tanstack/angular-query-experimental`

## Summary

The hooks generated for `angular-query` import from `@tanstack/angular-query-experimental`. On npm that package
is deprecated: "Moved to @tanstack/angular-query (devtools in @tanstack/angular-query-devtools)". Its last version
is 5.107.2, while `@tanstack/angular-query` is at 5.108.2. `bun install` prints the deprecation warning.

The hooks typecheck against the deprecated package. Changing only the import to `@tanstack/angular-query` 5.108.2
gives 10 errors, so the generator itself needs to change:

- 3 × TS2724: `InjectQueryOptions`, `InjectInfiniteQueryOptions` and `InjectMutationOptions` are not exported
- 7 × TS2554: `Expected 1 arguments, but got 2`, for calls such as `injectQuery(() => { … }, injectOptions)`

## Reproduction

Any document; for example the Train Travel API:

```ts
import { defineConfig } from 'hono-takibi'

export default defineConfig({
  input: 'https://raw.githubusercontent.com/readmeio/oas-examples/main/3.1/json/train-travel.json',
  output: './src/routes.ts',
  template: {},
  client: { output: './src/client.ts', baseUrl: '/' },
  'angular-query': { output: './src/hooks/angular-query.ts' },
})
```
