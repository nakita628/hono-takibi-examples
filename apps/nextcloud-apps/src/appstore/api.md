## Get all available categories


## Enable one apps

<a id="opIdapi-enable-app"></a>

> Code samples

```bash
curl https://cloud.example.com/ocs/v2.php/apps/appstore/api/v1/apps/enable \
  -X POST \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json' \
  -H "Authorization: Bearer ${ACCESS_TOKEN}" \
  -H 'OCS-APIRequest: true' \
  -d '{
    "appId": "string",
    "groups": [],
    "force": false
  }'
```

`POST /ocs/v2.php/apps/appstore/api/v1/apps/enable`

App will be enabled for specific groups only if $groups is defined
This endpoint requires admin access
This endpoint requires password confirmation

> Body parameter

```json
{
  "appId": "string",
  "groups": [],
  "force": false
}
```

<h3 id="enable-one-apps-parameters">Parameters</h3>

|Name|In|Type|Required|Description|
|---|---|---|---|---|
|OCS-APIRequest|header|boolean|true|Required to be true for the API request to pass|
|body|body|object|true|none|
|» appId|body|string|true|- The app to enable|
|» groups|body|[string]|false|- The groups to enable the app for|
|» force|body|boolean|false|- Whether to force enable the app even if Nextcloud version requirements are not met|
