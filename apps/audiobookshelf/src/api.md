## Get an author by ID

<a id="opIdgetAuthorById"></a>

> Code samples

```bash
curl http://localhost:3000/api/authors/e4bb1afb-4a4f-4dd6-8be0-e615d233185b \
  -H 'Accept: application/json' \
  -H "Authorization: Bearer ${ACCESS_TOKEN}"
```

`GET /api/authors/{id}`

Get an author by ID. The author's books and series can be included in the response.

<h3 id="get-an-author-by-id-parameters">Parameters</h3>

|Name|In|Type|Required|Description|
|---|---|---|---|---|
|include|query|string|false|A comma separated list of what to include with the author. The options are `items` and `series`. `series` will only have an effect if `items` is included. For example, the value `items,series` will include both library items and series.|
|id|path|[authorId](#schemaauthorid)|true|Author ID|

## Update an author by ID

<a id="opIdupdateAuthorById"></a>

> Code samples

```bash
curl http://localhost:3000/api/authors/e4bb1afb-4a4f-4dd6-8be0-e615d233185b \
  -X PATCH \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json' \
  -H "Authorization: Bearer ${ACCESS_TOKEN}" \
  -d '{
    "name": "Terry Goodkind",
    "description": "Terry Goodkind is a",
    "imagePath": "/metadata/authors/aut_z3leimgybl7uf3y4ab.jpg",
    "asin": "B000APZOQA"
  }'
```

`PATCH /api/authors/{id}`

Update an author by ID. The author's name and description can be updated. This endpoint will merge two authors if the new author name matches another author name in the database.

> Body parameter

```json
{
  "name": "Terry Goodkind",
  "description": "Terry Goodkind is a",
  "imagePath": "/metadata/authors/aut_z3leimgybl7uf3y4ab.jpg",
  "asin": "B000APZOQA"
}
```

<h3 id="update-an-author-by-id-parameters">Parameters</h3>

|Name|In|Type|Required|Description|
|---|---|---|---|---|
|id|path|[authorId](#schemaauthorid)|true|Author ID|
|body|body|object|false|The author object to update.|
|» name|body|[authorName](#schemaauthorname)|false|The name of the author.|
|» description|body|[authorDescription](#schemaauthordescription)|false|The new description of the author.|
|» imagePath|body|[authorImagePath](#schemaauthorimagepath)|false|The absolute path for the author image. This will be in the `metadata/` directory. Will be null if there is no image.|
|» asin|body|[authorAsin](#schemaauthorasin)|false|The Audible identifier (ASIN) of the author. Will be null if unknown. Not the Amazon identifier.|

## Match the author against Audible using quick match

<a id="opIdmatchAuthorById"></a>

> Code samples

```bash
curl http://localhost:3000/api/authors/e4bb1afb-4a4f-4dd6-8be0-e615d233185b/match \
  -X POST \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json' \
  -H "Authorization: Bearer ${ACCESS_TOKEN}" \
  -d '{
    "q": "Terry Goodkind",
    "asin": "B000APZOQA",
    "region": "us"
  }'
```

`POST /api/authors/{id}/match`

Match the author against Audible using quick match. Quick match updates the author's description and image (if no image already existed) with information from audible. Either `asin` or `q` must be provided, with `asin` taking priority if both are provided.

> Body parameter

```json
{
  "q": "Terry Goodkind",
  "asin": "B000APZOQA",
  "region": "us"
}
```

<h3 id="match-the-author-against-audible-using-quick-match-parameters">Parameters</h3>
