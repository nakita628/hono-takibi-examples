<h1 id="amazon-personalize-events">Amazon Personalize Events v2018-03-22</h1>

> Scroll down for code samples, example requests and responses. Select a language for code samples from the tabs above or the mobile navigation menu.

Amazon Personalize can consume real-time user event data, such as <i>stream</i> or <i>click</i> data, and use it for model training either alone or combined with historical data. For more information see <a href="https://docs.aws.amazon.com/personalize/latest/dg/recording-events.html">Recording Events</a>.

Base URLs:

* <a href="http://personalize-events.us-east-1.amazonaws.com">http://personalize-events.us-east-1.amazonaws.com</a> - The Amazon Personalize Events multi-region endpoint

* <a href="https://personalize-events.us-east-1.amazonaws.com">https://personalize-events.us-east-1.amazonaws.com</a> - The Amazon Personalize Events multi-region endpoint

* <a href="http://personalize-events.cn-north-1.amazonaws.com.cn">http://personalize-events.cn-north-1.amazonaws.com.cn</a> - The Amazon Personalize Events endpoint for China (Beijing) and China (Ningxia)

* <a href="https://personalize-events.cn-north-1.amazonaws.com.cn">https://personalize-events.cn-north-1.amazonaws.com.cn</a> - The Amazon Personalize Events endpoint for China (Beijing) and China (Ningxia)

## PutEvents

<a id="opIdPutEvents"></a>

> Code samples

```bash
curl https://personalize-events.us-east-1.amazonaws.com/events \
  -X POST \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json' \
  -H "Authorization: ${API_KEY}" \
  -d '{
    "trackingId": "string",
    "userId": "password",
    "sessionId": "string",
    "eventList": [
      {
        "eventId": {},
        "eventType": {},
        "eventValue": {},
        "itemId": {},
        "properties": null,
        "sentAt": {},
        "recommendationId": {},
        "impression": {},
        "metricAttribution": {
          "eventAttributionSource": {}
        }
      }
    ]
  }'
```

`POST /events`

Records user interaction event data. For more information see <a href="https://docs.aws.amazon.com/personalize/latest/dg/recording-events.html">Recording Events</a>.

> Body parameter

```json
{
  "trackingId": "string",
  "userId": "password",
  "sessionId": "string",
  "eventList": [
    {
      "eventId": {},
      "eventType": {},
      "eventValue": {},
      "itemId": {},
      "properties": null,
      "sentAt": {},
      "recommendationId": {},
      "impression": {},
      "metricAttribution": {
        "eventAttributionSource": {}
      }
    }
  ]
}
```
