# Authentication

* API Key (ApiKeyAuth)
    - Parameter Name: **X-N8N-API-KEY**, in: header.

- HTTP Authentication, scheme: bearer

* API Key (CookieAuth)
    - Parameter Name: **n8n-auth**, in: cookie.
