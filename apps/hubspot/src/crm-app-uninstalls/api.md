* API Key (developer_hapikey)
    - Parameter Name: **hapikey**, in: query.

- oAuth2 authentication.

    - Flow: authorizationCode
    - Authorization URL = [https://app.hubspot.com/oauth/authorize](https://app.hubspot.com/oauth/authorize)
    - Token URL = [https://api.hubapi.com/oauth/v1/token](https://api.hubapi.com/oauth/v1/token)

* API Key (private_apps)
    - Parameter Name: **private-app**, in: header.

* API Key (private_apps_legacy)
    - Parameter Name: **private-app-legacy**, in: header.

## Uninstall app

<a id="opIddelete-/appinstalls/2026-09/external-install"></a>

> Code samples

```bash
curl https://api.hubapi.com/appinstalls/2026-09/external-install \
  -X DELETE
```

`DELETE /appinstalls/2026-09/external-install`

Use this endpoint to uninstall your app from a customer's HubSpot account. If successful, this endpoint will return a 204 and the customer will receive an email notification that the developer has uninstall the app from their account.

> Example responses

> default Response

```json
null
```

### Properties

|Name|Type|Required|Restrictions|Description|
|---|---|---|---|---|

|correlationId|string(uuid)|true|none|A unique identifier for the request. Include this value with any error reports or support tickets|
